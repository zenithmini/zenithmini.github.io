# 台股進場判斷器

一個部署在 GitHub Pages、適合手機使用的台股 PWA。系統先以加權指數判斷整體市場，再分析輸入的上市股票或 ETF，最後輸出可解釋的進場與風險判斷。市場資料與核心運算由私人 API 處理，公開前端不包含完整策略程式；本金與風險設定只留在使用者裝置。

## 功能

- 支援證交所上市股票與 ETF，包括含英文字尾的代碼（例如 `0050`、`2330`、`00403A`）
- 自動計算近 120 日（新上市標的使用全部可用資料）的費波那契 23.6%／38.2%／50%／61.8%／78.6% 回檔位
- 顯示 1.272／1.618／2.0 費波那契擴展目標，以及現價最近支撐與壓力
- 新上市標的累積 40 日後可使用「費波那契觀察模式」；未滿 120 日不會在缺少 MA99 時誤給進場訊號
- 先檢查加權指數收盤、MA25／MA99 排列與 MA99 二十日斜率
- 大盤多頭使用完整部位、中性自動減半、空頭停止新的多方進場
- 計算 MA7／25／99、RSI14、KD(14,3,3)、MACD(12,26,9)、ATR14、20 日均量
- 六道檢查：趨勢、價格結構、回檔、轉強、禁止追價、流動性
- 桌機左側選單與手機滑出選單，可切換個股分析、0050 機會雷達及策略說明
- 0050 機會雷達每日分批掃描 50 檔成分股，分類為條件已符合、接近進場區、關鍵突破觀察及暫不適合
- 顯示參考進場價、2ATR／近期低點停損，以及「每承擔 1 元損失、目標爭取 3 元」的目標價
- 依資金、單筆風險與單檔上限計算張數／零股
- 以白話動態範例說明預計投入金額、跌到停損時約損失與股數上限
- 自選股、最近分析與離線快取只保存在使用者手機瀏覽器
- PWA，可加入手機主畫面

## 部署到 GitHub Pages

1. 在 GitHub 建立一個空白 repository，例如 `tw-stock-signal`。
2. 將本專案所有檔案上傳到 repository 的 `main` 分支。
3. 預設會連線到 `https://tw-stock-signal-api.market-signal-tools.workers.dev`。
4. 若日後更換 API 網址，可到 repository 的 **Settings → Secrets and variables → Actions → Variables**，新增或修改 `SIGNAL_API_URL`（不要加結尾斜線）。
5. 到 **Settings → Pages → Build and deployment**，將 Source 選為 **GitHub Actions**。
6. 等待 Actions 裡的 `Deploy GitHub Pages` 完成。
7. 網址會是 `https://你的帳號.github.io/你的-repository-名稱/`。

之後只要 push 到 `main`，GitHub Actions 會自動重新建置與部署。建置流程會將資源網址改成相對路徑，因此 repository 名稱不需固定。

## 本機執行

需要 Node.js 22：

```bash
npm ci
npm run dev
```

建立 GitHub Pages 用的正式靜態網站：

```bash
npm run build:pages
```

GitHub Pages 使用的靜態檔會在 `dist/client`。

- 個股分析中間／底部與 0050 雷達中間／底部，各使用已建立的回應式展示廣告單元；Google 回傳 `unfilled` 時版位會自動收合，不留下大塊空白。

## 策略摘要

核心策略先判斷加權指數環境，再檢查個股趨勢、位置、動能、流動性與風險，並以費波那契輔助定位。公開網頁只呈現判斷結果與必要說明，完整門檻、權重、指標計算及價格推導保留在私人分析 API。部位張數則依使用者在裝置上設定的本金、風險比例與大盤係數計算，不會上傳這些個人設定。

## 已知限制

- 目前只支援證交所上市市場；上櫃股票需改接櫃買中心資料。
- 使用證交所原始成交價，不是還原股價。除權息、分割後需人工確認；系統偵測到近 100 日超過 15% 的跳空時會停止給進場訊號。
- 日線收盤後分析，不是盤中即時報價，也不會連接券商自動下單。
- 加權指數與個股都採收盤日線；不是盤中大盤燈號。
- 私人分析 API、證交所公開端點或網路暫時不可用時，網頁只會使用這台裝置近期成功分析的快取；沒有可靠的大盤資料時不提供新訊號。

## 風險聲明

本工具是規則化研究與風險管理輔助，不是投資建議、報酬保證或自動下單服務。實際交易前仍需評估個人財務狀況、公司事件、除權息與市場流動性。
